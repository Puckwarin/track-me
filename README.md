# Track Me

เว็บแอปบันทึกสุขภาพส่วนตัว ครอบคลุมอาหาร การออกกำลังกาย ประจำเดือน อาการและผิว ผลตรวจ น้ำหนัก สัตว์เลี้ยง และของใช้ ซิงค์ข้อมูลส่วนตัวผ่าน Google Sign-in และ Firebase Firestore พร้อมใช้งานแบบ PWA

- แอป: https://puckwarin.github.io/track-me/
- ตั้งค่าครั้งแรกหรือสร้างโปรเจกต์ใหม่: [docs/SETUP.md](docs/SETUP.md)
- Release และ tag: [GitHub Releases](https://github.com/Puckwarin/track-me/releases)

## ความสามารถหลัก

- บันทึกอาหารและโภชนาการ พร้อมค้นจาก Open Food Facts, USDA และ Gemini; ตรวจแหล่งข้อมูล/ฉลากก่อนบันทึก
- สรุปอาหารและการออกกำลังกายรายสัปดาห์และรายเดือน
- ติดตามประจำเดือน อาการ/ผิว ผลตรวจ น้ำหนัก และสัดส่วน
- บันทึกการดูแลและอาหารสัตว์เลี้ยง รวมถึงของใกล้หมดอายุ/ใกล้หมดสต๊อกและรอบเปลี่ยนของ
- สำรองและกู้คืนข้อมูล; เก็บ API keys ในเบราว์เซอร์ของอุปกรณ์นั้น
- ใช้ได้แบบ PWA และออฟไลน์สำหรับหน้าที่แคชไว้; การค้นหาออนไลน์ยังต้องใช้อินเทอร์เน็ต

แหล่งโภชนาการภายนอกอาจมีโควตา จำกัดการเรียก หรือหยุดให้บริการชั่วคราว Open Food Facts มีลิงก์ค้นหาบนเว็บไซต์เป็นทางเลือก และ Gemini อาจตอบช้า/เต็มโควตาได้

## พัฒนาในเครื่อง

ต้องใช้ Node.js 20 ขึ้นไป

```bash
npm ci
npm run dev
npm run build
```

## โครงสร้างสำคัญ

- `.github/workflows/build.yml` — ตรวจ build สำหรับ pull request และ push ไป main
- `.github/workflows/pages.yml` — build และ deploy GitHub Pages เมื่อมีการ push ไป main
- `firestore.rules` — Firestore Rules สำหรับข้อมูลของผู้ใช้
- `firestore.rules.migration` — Rules ชั่วคราวสำหรับขั้นตอนย้ายข้อมูลเก่า
- `public/` — ไอคอนและไฟล์สาธารณะที่ Vite/PWA ใช้
- `src/` — โมดูลแอป

การย้อนเวอร์ชันเว็บให้สร้าง revert commit/PR จาก commit ที่ต้องการย้อน แล้ว merge เพื่อให้ GitHub Pages deploy จาก main อีกครั้ง Tag เป็นจุดอ้างอิงเวอร์ชัน ไม่ได้ย้อน production ให้อัตโนมัติ และการเปลี่ยน Firestore Rules ต้องพิจารณาแยกจากการย้อนเว็บ
