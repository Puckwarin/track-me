# Track Me

เว็บแอปจัดการชีวิตและบันทึกสุขภาพส่วนตัว ครอบคลุมอาหาร การออกกำลังกาย รายรับ-รายจ่าย ประจำเดือน อาการและผิว น้ำหนักและสัดส่วน สัตว์เลี้ยงและผลตรวจ บันทึกแจ้งเตือน และของใช้ ซิงค์ข้อมูลส่วนตัวผ่าน Google Sign-in และ Firebase Firestore พร้อมใช้งานแบบ PWA

## ความสามารถหลัก

### 1. การวางแผน & การเงิน
- **หน้า Home, Weekly Planner รายสัปดาห์ จันทร์–อาทิตย์ & ย้ายวันงาน (`src/home.js`, `src/planner.js`, `src/home.css`, `src/summary.js`):** หน้า Home แสดง **Weekly Planner** (ทีละ 1 สัปดาห์ จันทร์–อาทิตย์ พร้อมปุ่ม **`"วันนี้"`** แบบไม่มีลูกศรเลื่อนซ้าย-ขวา, แถบปฏิทินเลื่อนซ้าย–ขวาหลายสัปดาห์, ปุ่ม `+ เพิ่มงาน`, ปุ่มหุบ/ยุบ `.pl-collapse-btn`, และ inline feedback ทันที `#pl-feedback-slot`; บน Desktop `>= 1024px` แสดงกระดาน 7 คอลัมน์ จ–อา รองรับ Drag & Drop ข้ามวันและปุ่ม **ย้าย**, บน Mobile `< 1024px` แสดงรายการแนวตั้งปุ่ม `>= 44px` พร้อมปัดซ้ายแก้ไข/ลบ), แสดงส่วน **ทางลัดปักหมุด (`#home-shortcuts`)** เฉพาะเมื่อผู้ใช้เลือกทางลัดไว้ (สูงสุด 8 รายการ), การ์ด **สรุปภาพรวมวันนี้** แสดงข้อความให้กำลังใจหมุนเวียน 28 ข้อความตามวันที่, Donut Chart พร้อมสเกลเทียบเป้าหมายแคลอรี่, คอนทราสต์ธีม Cool Sky Blue & Navy และ Floating Hover/Tap Tooltip ป้องกันล้นขอบจอ และกล่องมาโคร 4 ช่อง (**โปรตีน / คาร์บ / ไขมัน** และกล่องรวม **น้ำตาล · โซเดียม** แสดง `Xg · Ymg` พร้อม `"เฉพาะรายการที่ระบุ"`, เรียง 2×2 บน Desktop); ด้านล่างแสดง **สรุปภาพรวมทั้งหมด** แบบแนวนอน (แยกการ์ด **ประจำเดือนล่าสุด**, **รอบเฉลี่ย**, **น้ำหนักล่าสุด**, **สัดส่วน**, **การนอน**, **ก้าวเดิน**, **การเงินเดือนนี้** ที่แสดงคำว่า **"ยอดรวม"** บนบรรทัดใหม่ และ **ออกกำลังกายสัปดาห์นี้**, พร้อมกดเข้าหน้านั้นได้ทันทีและมีปุ่มลัดไปยัง **`ประวัติ & รายงาน`**); หน้าต่าง **จัดการ & แก้ไข** ผูกวัน จ–อา เฉพาะสัปดาห์ที่กำลังเลือกอยู่พร้อมปุ่มเลือกชุดวันทุกปุ่มกดซ้ำเพื่อล้างวันได้ และปุ่มล่างฟอร์ม **"ยกเลิก"** / **"บันทึก"** ส่วนหน้าต่าง **จัดการ & ย้ายวัน** ใช้ปุ่ม **"ย้ายวัน"**, **"ทำเสร็จ"** / **"ยังไม่ทำ"**, และ **"แก้ไข"** / **"ลบ"** โดยยังคงรองรับข้อมูลเดิมที่มีอยู่ (`every`/`A`/`B`/`once`)
- **รายรับ-รายจ่าย (`expense_records`) แยกเป็นแท็บหลัก "การเงิน" + สแกนสลิปหลายใบ & Statement:** เก็บข้อมูลแยก 1 รายการ = 1 เอกสาร (ลดความเสี่ยงข้อมูลทับกันข้ามอุปกรณ์และส่งออก CSV รายเดือนได้) อ่านสลิปหลายรูปด้วย `tesseract.js` (`tha+eng`) แบบออฟไลน์ในเบราว์เซอร์เท่านั้น รองรับแชร์รูปสลิปตรงเข้าแอปผ่าน PWA Web Share Target และล้างรูปภาพจากหน่วยความจำทันทีหลังอ่านเสร็จ; นำเข้า Statement โดยแก้ไขชื่อผู้รับเงิน/ร้านค้า/ที่มาและหมายเหตุได้ ล้างกล่องรอตรวจได้, พับช่องเสริม (ร้านค้า/หมายเหตุ) และประวัติรายการตั้งแต่ลำดับที่ 6 ไว้ในเมนูพับ `<details>` เมื่อไม่ได้กรอง, ระบบเรียนรู้หมวดจากรายการที่บันทึก/นำเข้าอัตโนมัติ, มีงบรายเดือนแยกตามหมวด และ **วิเคราะห์รายการจ่ายซ้ำทุกเดือนเพื่อประเมินรายจ่ายประจำต่อเดือน** พร้อมยืนยันก่อนบันทึก
- **แจ้งเตือนภาษาธรรมชาติ & ของใช้/สต๊อก:** พิมพ์เงื่อนไขแจ้งเตือนช่องเดียวพร้อม Live Preview (เช่น วันเสาร์ที่สามของเดือน, ปีหน้า, วันเดียวกับอาบน้ำหมา, ทุกวันเสาร์ที่ไม่ได้อาบน้ำหมา); ของใช้มีปุ่ม `−`/`+` 44px กดง่ายและสแกนวันหมดอายุหลายรูปพร้อมตัวเลข `%` และหน้าต่างยืนยันก่อนบันทึก
- **แจ้งเตือนอัตโนมัติ 12:15 น. แม้ไม่ได้เปิดแอป:** ใช้ Web Push Notification (VAPID) ร่วมกับ GitHub Actions ส่งสรุป Planner, ตารางนัด และรอบเดือนอัตโนมัติฟรี พร้อมโหมด **ซ่อนรายละเอียดส่วนตัวบนหน้าจอล็อก** เป็นค่าเริ่มต้น (ตั้งค่าในการ์ด **การแจ้งเตือน** หน้าตั้งค่า)

### 2. สุขภาพ โภชนาการ & การออกกำลังกาย
- **บันทึกอาหารและโภชนาการ:** แถบเลือกวันที่พร้อมแถบหลายสัปดาห์เลื่อนซ้าย–ขวา (`#f-week-strip`) และปุ่ม **`"วันนี้"`** แบบไม่มีลูกศร, การ์ดสรุปและกราฟ **Donut Chart** รายมื้อรูปแบบเดียวกับหน้าหลัก (แสดง % ตรงกลางสเกลเทียบเป้าหมายแคลอรี่, สีแยกแยะชัดเจนในธีม Cool Sky Blue & Navy, กล่องมาโคร 4 ช่องเรียง 2×2 บน Desktop **โปรตีน / คาร์บ / ไขมัน / น้ำตาล · โซเดียม**, และ **Floating Hover/Tap Tooltip** พร้อม Collision Detection ป้องกันล้นขอบจอ โดยไม่แสดงแถบ Legend หรือข้อความแนะนำใต้กราฟ) พร้อมกรอบ **คำแนะนำโภชนาการ (`#f-advice`)** แบบจุดใต้เส้นขีดในการ์ดเดียวกัน; ฟอร์มบันทึกอาหารมี **แถบรายการโปรดด่วน (`#f-fav-strip`, สูงสุด 5 ชิปบนมือถือ / 10 ชิปบนคอมพิวเตอร์)** เหนือช่องกรอกชื่อเมนู, ระบบอนุมานโหมดหน่วย/กรัมอัตโนมัติ (`inferFoodInputMode`) จากตัวเลขที่กรอกโดยไม่ต้องเลือกโหมดแยก, ปุ่มสแกน **บาร์โค้ด** และ **ฉลากโภชนาการ** (พร้อมพรีวิวชั่วคราวฝั่ง Client โดยไม่บันทึกรูปลงฐานข้อมูล), **เพิ่ม/แก้ไขเมนู & คลังอาหาร** แบบตาราง/การ์ด (คลิกดาวบันทึกโปรดในตัวแก้ไข, ตัดช่อง % กินได้ออก), **เพิ่มอาหารหลายเมนูพร้อมกัน**, **ค้นหาโภชนาการอัตโนมัติ** พร้อมแผงคำนวณปริมาณ และ **ประวัติอาหาร** พร้อมแถบวัน 7 วัน, ค้นหาอัตโนมัติ และหุบ/กางทั้งรายวันและรายมื้อ; รายการอาหารของวันแบ่งตามมื้อแบบหุบ/กางได้พร้อมแสดง **โปรตีนรวม (`P ...g`)** บนทุกขนาดจอ, **เลือกทั้งมื้อ**, **ลากวาง (Drag & Drop)** ย้ายมื้อ, **ปัดซ้ายแก้ไข/ลบ & ปัดขวาโปรด** บนมือถือ `< 1024px` และปุ่ม **★ โปรด / แก้ไข / ลบ** บน Desktop `>= 1024px`
- **ออกกำลังกาย (Workout Hub):** แบ่ง 3 แท็บย่อยกระชับ (**วางแผน & บันทึก**, **ประวัติ & แผน**, **เทมเพลต**), เคลียร์ฟอร์ม **วางแผน & บันทึก** อัตโนมัติทุกครั้งที่เข้าหรือสลับแท็บกลับมา, เติมลิงก์ `รูป/GIF ประกอบท่า` อัตโนมัติเมื่อชื่อท่าซ้ำ, กลุ่ม **วอร์มอัพ / ท่าหลัก / คูลดาวน์** หุบ-กางได้, ปุ่ม **ยกเลิก** ด้านซ้ายสี Rose, วางแผนรายสัปดาห์ จ–อา, **เทมเพลตสำเร็จรูป 5 ชุด (0 โทเค็น)** + **นำเข้าตารางจากข้อความหรือตาราง** และแก้ไข Template ผ่าน Preview ทันที, กรอบรูปประกอบท่า (`object-contain` + แตะซูม), โหมดเริ่มตามแผนพร้อมตัวจับเวลาพัก `30 / 60 / 90` วินาที (กะพริบสีแดงเมื่อครบ 0), ซ่อนท่าที่ทำครบเซตพร้อมปุ่ม **`แสดงท่าที่เสร็จแล้ว (X)`**, ประเมินหลังฝึกเฉพาะ **ท่าหลัก** ร่วมกับ 3 หัวข้อ (**สถานะการฝึก**, **ความเหนื่อย**, **อาการระหว่างหรือหลังฝึก**) และ **การฟื้นตัวในวันถัดไป** (`nextDayRecovery` พร้อม inline feedback และ optimistic toast ทันที), พับประวัติรายการตั้งแต่ลำดับที่ 6 เมื่อไม่ได้กรอง, และสรุป **`ทำจริง x เซต`** (ท่าหลัก) กับ **`x นาที รวม`**
- **ประวัติ & รายงาน, ร่างกาย, การนอน/ก้าวเดิน (Zepp) & รอบเดือน:** เมนู **`ประวัติ & รายงาน`** (`overview`, ยกระดับขึ้นเป็นเมนูหลักต่อจากหน้าหลักบน Desktop และเข้าได้จาก `#quick-sheet` เมนู `+` หรือปุ่มบนหน้าหลักบนมือถือ) รวมมุมมอง **ภาพรวม & สรุป** (`dashboard.js` ย้อนหลัง 3 / 6 / 12 เดือน + `weekly.js` พร้อม hover tooltip ทุกกราฟ) และสลับไป **รายงาน (PDF / CSV)** (`reports.js` รวมถึงข้อมูลประเมินหลังฝึกและการฟื้นตัววันถัดไป) ในจุดเดียว; หน้ายาวต่าง ๆ (**ร่างกาย, อาการ, ประจำเดือน, ดูแล, ของใช้, ออกกำลังกาย, การเงิน**) แบ่งแท็บย่อยด้วย `.tm-seg` เพื่อความกระชับบนมือถือ; ติดตามประจำเดือน, อาการและผิว, กราฟสัดส่วนร่างกาย และบันทึก **การนอนหลับ & ก้าวเดิน** (กรอกเองและนำเข้า Zepp CSV 3 รูปแบบโดยไม่ใช้ AI)

### 3. ดูแลสัตว์เลี้ยง
- **โปรไฟล์ & โภชนาการสัตว์เลี้ยง:** บันทึกน้ำหนัก คำนวณพลังงาน, เลือกจากอาหารเดิมที่เคยบันทึกได้ใน 1 คลิก (0 โทเค็น), และสแกนซองอาหารสัตว์เลี้ยงหลายรูปพร้อมความคืบหน้า `%` และหน้าต่างตรวจยืนยัน
- **บันทึกอาการน้องหมา & ผลตรวจสุขภาพ:** บันทึกระดับอาการรายวัน 6 ด้าน (ความอยากอาหาร, พลังงาน/ซึม, อุจจาระ, อาเจียน, ผิวหนัง, ไอ/หายใจ) และอุณหภูมิ (°C) แยกจากระบบแจ้งเตือน พร้อมบันทึกผลตรวจสุขภาพ (มีชุดเทมเพลต `CBC / ค่าไต / ค่าตับ / น้ำตาล & ไขมัน` และวางข้อความหลายบรรทัด 0 โทเค็น), กรองดูเฉพาะ **ค่าเลือดผิดปกติ (Abnormal)**, และสแกนใบผลเลือดหลายรูปพร้อมความคืบหน้า `%` และหน้าต่างตรวจยืนยันก่อนบันทึก

### 4. การตั้งค่า & ประสบการณ์ใช้งาน
- **เริ่มต้นใช้งานสำหรับบัญชีใหม่:** แนะนำโปรไฟล์พื้นฐาน, คีย์ AI และการแจ้งเตือนแบบเลือกทำได้ พร้อมภาพประกอบ SVG ในเครื่อง (`src/onboarding.js`); ผู้ใช้เดิมไม่ถูกบังคับผ่านขั้นตอนนี้ และความคืบหน้าจะกลับมาต่อได้บนอุปกรณ์เดิม
- **AI Chat Assistant & โหมดแพตเทิร์น 0 โทเค็น (ผู้ช่วยส่วนตัวมุมขวาล่าง):** มีโหมด **⚡ แพตเทิร์น (0 โทเค็น)** ที่ประมวลผลคำสั่งจดและเช็กสรุปในเครื่อง 100% โดยไม่ใช้ AI และไม่ต้องมี API Key (เปิดเช็กแพตเทิร์นในเครื่องก่อนเรียก AI เป็นค่าเริ่มต้น พร้อมลด `HISTORY_LIMIT = 12` และแนบ tools เฉพาะคำถามที่เกี่ยวกับ Track Me เพื่อประหยัดโทเค็น) และเมื่อเรียก AI สามารถคุยได้ทุกเรื่องด้วย **5 บทบาทเฉพาะทาง** (`คุยทั่วไป`, `โค้ชสุขภาพ`, `วางแผน & เงิน`, `วิเคราะห์ลึก`, `ตอบไว`) ที่ route โมเดลอัตโนมัติพร้อมคำสั่งเพิ่มเติมเองได้, คั่น cooldown แยกตามรายโมเดลเมื่อติดโควตา 429, แสดงผล Markdown, ช่องพิมพ์หลายบรรทัด + ปุ่มหยุดตอบ, เก็บประวัติแชทล่าสุดในอุปกรณ์, มีการ์ดยืนยันก่อนบันทึกข้อมูลสำคัญ, ปุ่มยกเลิกย้อนหลัง และระบบป้องกัน Prompt Injection (ทำงานฝั่ง Client ด้วยคีย์ Gemini, Groq หรือ OpenRouter ที่ตั้งค่าไว้)
- **ดูตัวอย่างโดยไม่เข้าสู่ระบบ (Preview Mode, `src/preview.js`):** หน้าเข้าสู่ระบบมีปุ่ม **ดูตัวอย่างก่อนใช้งาน** สำหรับเปิดสำรวจแอปด้วยข้อมูลตัวอย่างในหน่วยความจำชั่วคราวครบทุกหมวด (อาหาร การเงิน ออกกำลังกาย ร่างกาย รอบเดือน สัตว์เลี้ยง ของใช้ ผลแล็บ และแพลนเนอร์) พร้อมแถบสถานะและปุ่มออกจากโหมดตัวอย่างที่ล้างข้อมูลชั่วคราวออกอัตโนมัติ โดยไม่เขียนข้อมูลลง Firebase หรือบัญชีจริง
- **Pastel Blue-Primary Brand & UI/Accessibility:** ใช้ชุดสี Pastel โทนฟ้าเป็นหลักเพียงชุดเดียวผ่าน Semantic Tokens ใน `src/design-tokens.css` (`#EAF3FD` app bg, `#4A90D4` pastel primary blue, `#CBE5FC`/`#E3F1FB` soft sky accents, `#194971` ink สำหรับความคมชัดในการอ่าน, `accent-brand` สำหรับ checkbox/radio ทั้งแอป และโลโก้โทนฟ้า `#e1f5fe` / ขอบ `#b3e5fc` / ไอคอน `#03a9f4` เหมือนหน้าล็อกอินทุกจุด); ไม่มีตัวเลือกธีมและไม่มีสีเฉพาะหมวดหมู่; สีสถานะ Success, Warning และ Error ยังคงแยกชัดเจน ใช้ชุดไอคอน **Phosphor Regular** (`@phosphor-icons/core` ใน `src/icons.js`) แบบ inline SVG ทั้งแอปและทำงานออฟไลน์ 100%, Desktop ใช้ Sidebar ซ้ายแสดงหมวดหลักตลอดเวลาพร้อมขยาย/ยุบเมนูย่อย, Mobile ใช้แถบนำทาง 5 ตำแหน่ง (**หน้าหลัก**, **อาหาร**, **โลโก้แอปเปิด Bottom Sheet ที่มีทางลัด "ประวัติ & รายงาน"**, **ออกกำลัง** ไฮไลต์ครอบคลุมทุกหน้าย่อยกลุ่มสุขภาพ, **ดูแล**), แสดงคำแนะนำปัดซ้าย `.tm-swipe-hint` เฉพาะบนหน้าจอมือถือที่มีรายการ, ใช้ตัวสลับแท็บ `.tm-seg` และปุ่ม `.pl-collapse-btn` สำหรับพับส่วนยาวใน Planner และ Settings, ปรับแต่งลำดับวิดเจ็ตหน้าแรกด้วยการ **Drag & Drop** (เมาส์และสัมผัส) หรือปุ่มลูกศร, เปลี่ยนชื่อมื้ออาหารในโปรไฟล์แล้วซิงค์ชื่อมื้อไปยังบันทึกอาหารย้อนหลัง (`food_records`) อัตโนมัติ, คงพื้นที่กด `>= 44px` และ `label[for]`/`aria-label` บนฟอร์ม ตัวกรอง ชิป ปุ่มปิด Modal และปุ่มจัดการทั้งแอป, แสดงเลขเวอร์ชันของเว็บแอป (`src/version.js`), มี focus trap + ปิดด้วย `Escape` + คืน focus ใน Modal/Bottom Sheet/Drawer/Onboarding, ปุ่ม **AI Chat** บน Header ขวาบน, ปุ่มเลื่อนหน้าจออัตโนมัติ 1 ปุ่ม, Combobox ค้นหาอาหาร, แถบวันหลายสัปดาห์, Slider ชั่วโมงนอน, ตัวนับเลข `animateNumberTicker`, สำรองและกู้คืนข้อมูล และทดสอบคีย์ API ได้ในหน้าตั้งค่า
- ใช้ได้แบบ PWA และออฟไลน์สำหรับหน้าที่แคชไว้; หน้าและโมดูลที่ยังไม่เปิดในหน้าแรก (**รายจ่าย, แชท AI, สัตว์เลี้ยง, ของใช้, ผลแล็บ, แพลนเนอร์, อาหาร, สรุป, แจ้งเตือน, ตั้งค่า, แดชบอร์ด `dashboard.js`, รายงาน และออกกำลังกาย**) จะถูก **Lazy Load** เฉพาะเมื่อคลิกเปิดใช้งานเพื่อให้เปิดแอปได้เร็วขึ้น (การค้นหาออนไลน์และ AI ยังต้องใช้อินเทอร์เน็ต)

> **หมายเหตุ:** แหล่งโภชนาการภายนอกอาจมีโควตา จำกัดการเรียก หรือหยุดให้บริการชั่วคราว Open Food Facts/USDA อาจมีข้อจำกัดเครือข่ายและโควตา ส่วน Gemini/Groq เปลี่ยนข้อกำหนดหรือโควตาได้ Hiwpinto ใช้ bookmark helper เพราะ browser ป้องกันการอ่านพอร์ทัลล็อกอินข้ามโดเมนโดยตรง

> **AI Provider:** แอปสลับ Gemini → Groq → OpenRouter ตามคีย์ที่ตั้งไว้และสถานะโควตา; คีย์ API อยู่ฝั่ง browser และ provider จะได้รับ prompt/รูปภาพที่ส่งวิเคราะห์ โปรดอ่าน [คู่มือ AI Service](docs/AI_SERVICE.md) ก่อนใส่ข้อมูลส่วนตัว

## ซิงค์เมนูอาหารคลีนประจำสัปดาห์ (Hiwpinto)

1. เข้าเว็บไซต์ Hiwpinto ล็อกอินให้เรียบร้อย แล้วเปิดหน้า **รายการเมนูของบิลสัปดาห์ถัดไป**
2. คลิกปุ่ม **Sync Hiwpinto** บนแถบ Bookmark ด้านบน ระบบจะคัดลอกข้อมูลเมนูที่มีโภชนาการลง Clipboard อัตโนมัติ
3. กลับมาที่หน้าต่าง **Sync Data Hiwpinto** ใน Track Me กด **วางจาก Clipboard** แล้วกด **ตรวจเมนูสัปดาห์ถัดไป** เพื่อตรวจรายการและนำเข้าคลังอาหาร

เมนูที่ระบุว่ามีข้าวจะประมาณข้าวเดิมจากคาร์บของร้าน แล้วเพิ่มเฉพาะส่วนที่ขาดจากเป้าหมาย 180g; ค่า Riceberry เป็นค่าอ้างอิงชั่วคราว ส่วนคาร์บรวมอาจมาจากซอส ผัก หรือส่วนผสมอื่นได้ เมื่อแก้เมนู ระบบคำนวณใหม่จากค่าโภชนาการร้านที่เก็บแยกไว้ และไม่ปรับรายการเก่าจนกว่าจะกดบันทึกเอง

*(หากยังไม่ได้สร้าง Bookmark ให้ทำตาม [วิธีตั้งค่าครั้งแรกใน docs/SETUP.md](docs/SETUP.md#hiwpinto-sync-helper-ทำครั้งเดียว))*

## โครงสร้างโปรเจกต์สำคัญ

- github/workflows/build.yml — lint, tests, Firestore Emulator, build และ deploy GitHub Pages หลัง checks ผ่านบน main
- github/workflows/daily-push.yml — ส่ง Web Push Notification สรุปแผนวันนี้และแจ้งเตือนอัตโนมัติเวลา 12:15 น. (UTC+7)
- scripts/daily-push.mjs — สคริปต์ Node.js อ่าน Firestore และส่ง Web Push (VAPID)
- scripts/check-lockfile.mjs — ตรวจความสอดคล้องของ `package.json` และ `package-lock.json` (รวม optional platform dependencies)
- firestore.rules — Firestore Rules สำหรับข้อมูลของผู้ใช้
- firestore.rules.migration — Rules ชั่วคราวสำหรับขั้นตอนย้ายข้อมูลเก่า
- public/ — ไอคอน, push-sw.js และไฟล์สาธารณะที่ Vite/PWA ใช้
- src/ — โมดูลหลักของแอป
- src/food.js และโมดูล `food*` — หน้าบันทึกอาหาร, parser, การคำนวณ, validation, Firestore service และ UI ย่อย (ดู [docs/FOOD_MODULES.md](docs/FOOD_MODULES.md))

> **การย้อนเวอร์ชันเว็บ (Rollback):** ให้สร้าง revert commit/PR จาก commit ที่ต้องการย้อน แล้ว merge เพื่อให้ GitHub Pages deploy จาก main อีกครั้ง (Tag เป็นเพียงจุดอ้างอิงเวอร์ชัน ไม่ได้ย้อน production ให้อัตโนมัติ และการเปลี่ยน Firestore Rules ต้องพิจารณาแยกจากการย้อนเว็บ)
