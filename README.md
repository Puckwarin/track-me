# Track Me

เว็บแอปจัดการชีวิตและบันทึกสุขภาพส่วนตัว ครอบคลุมอาหาร การออกกำลังกาย รายรับ-รายจ่าย ประจำเดือน อาการและผิว น้ำหนักและสัดส่วน สัตว์เลี้ยงและผลตรวจ บันทึกแจ้งเตือน และของใช้ ซิงค์ข้อมูลส่วนตัวผ่าน Google Sign-in และ Firebase Firestore พร้อมใช้งานแบบ PWA

## ความสามารถหลัก

### 1. การวางแผน & การเงิน
- **หน้า Home แบบ Calm Wellness, Weekly Planner ด้านบนสุด, Week A/B & กิจกรรมวันเดียว:** แสดงการ์ด **Weekly Planner** ไว้ด้านบนสุดของหน้าแรกพร้อมเช็กลิสต์สิ่งที่ต้องทำในวันนั้น ๆ ทันที (ปรับลำดับวิดเจ็ตได้ในตั้งค่า), จัดวางเลย์เอาต์แบบ Calm Wellness (`src/home.css`) แสดงวงแหวนแคลอรี่พร้อมตัวนับเลข `animateNumberTicker`, แมโคร, กิจกรรมรายวัน, แถบวันที่เลื่อนซ้าย-ขวาได้, เมนู **วางแผน** (`กิจกรรม`, `ออกกำลังกาย`, `นัดหมาย`), รองรับ **กิจกรรมสลับสัปดาห์ (Week A / Week B)** และ **กิจกรรมวันเดียว (`once`)**, และแสดงป้ายเตือนนัดหมายด้านบน
- **รายรับ-รายจ่าย (`expense_records`) แยกเป็นแท็บหลัก "การเงิน" + สแกนสลิปหลายใบ & Statement:** เก็บข้อมูลแยก 1 รายการ = 1 เอกสาร (ลดความเสี่ยงข้อมูลทับกันข้ามอุปกรณ์และส่งออก CSV รายเดือนได้) อ่านสลิปหลายรูปด้วย `tesseract.js` (`tha+eng`) แบบออฟไลน์ในเบราว์เซอร์เท่านั้น รองรับแชร์รูปสลิปตรงเข้าแอปผ่าน PWA Web Share Target และล้างรูปภาพจากหน่วยความจำทันทีหลังอ่านเสร็จ; นำเข้า Statement โดยแก้ไขชื่อผู้รับเงิน/ร้านค้า/ที่มาและหมายเหตุได้ ล้างกล่องรอตรวจได้, พับช่องเสริม (ร้านค้า/หมายเหตุ) และประวัติรายการตั้งแต่ลำดับที่ 6 ไว้ในเมนูพับ `<details>` เมื่อไม่ได้กรอง, ระบบเรียนรู้หมวดจากรายการที่บันทึก/นำเข้าอัตโนมัติ, มีงบรายเดือนแยกตามหมวด และ **วิเคราะห์รายการจ่ายซ้ำทุกเดือนเพื่อประเมินรายจ่ายประจำต่อเดือน** พร้อมยืนยันก่อนบันทึก
- **แจ้งเตือนภาษาธรรมชาติ & ของใช้/สต๊อก:** พิมพ์เงื่อนไขแจ้งเตือนช่องเดียวพร้อม Live Preview (เช่น วันเสาร์ที่สามของเดือน, ปีหน้า, วันเดียวกับอาบน้ำหมา, ทุกวันเสาร์ที่ไม่ได้อาบน้ำหมา); ของใช้มีปุ่ม `−`/`+` 44px กดง่ายและสแกนวันหมดอายุหลายรูปพร้อมตัวเลข `%` และหน้าต่างยืนยันก่อนบันทึก
- **แจ้งเตือนอัตโนมัติ 12:15 น. แม้ไม่ได้เปิดแอป:** ใช้ Web Push Notification (VAPID) ร่วมกับ GitHub Actions ส่งสรุป Planner (รวมรอบ Week A/B) และนัดหมายเชื่อมโยงอัตโนมัติฟรี พร้อมโหมด **ซ่อนรายละเอียดส่วนตัวบนหน้าจอล็อก** เป็นค่าเริ่มต้น

### 2. สุขภาพ โภชนาการ & การออกกำลังกาย
- **บันทึกอาหารและโภชนาการ:** มีตัวสลับมุมมองแบบ Segmented Tab (**บันทึกอาหาร / สรุปโภชนาการ**), แถบวัน 7 วันพร้อมช่องเลือกวันที่ (ตัดปุ่มเมื่อวาน/วันนี้/พรุ่งนี้ และปุ่ม +/- 100 kcal, +/- 50g ออก), **Pie Chart สัดส่วนพลังงานรายมื้อ**, คำแนะนำจากเกณฑ์หลายปัจจัย (`buildFoodAdvice`), รายการอาหารแบบกลุ่มรายมื้อพร้อม **เลือกทั้งมื้อ**, **ลากวาง (Drag & Drop)** ย้ายมื้อ, **ปัดซ้ายเพื่อแก้ไข/ลบ**, และ **ปัดขวาเพื่อบันทึกรายการโปรด**; **สแกนอาหาร/ฉลาก/บาร์โค้ดในปุ่มเดียวหลายรูปพร้อมกัน (`i/N`, `%`)** โดยระบบลองอ่านบาร์โค้ดและ **OCR ฉลากในเครื่อง (`tesseract.js`, 0 โทเค็น · ไม่ใช้ AI)** ก่อนอัตโนมัติ; **เพิ่มอาหารหลายเมนูพร้อมกัน (Bulk / Quick Add)**, **ค้นหาโภชนาการอัตโนมัติ**, และอัปเดตข้อมูลอัตโนมัติเมื่อแก้ไขรายการในคลังอาหาร
- **ออกกำลังกาย (Workout Hub):** แบ่ง 3 แท็บย่อยกระชับ (**วางแผน & บันทึก**, **ประวัติ & 7 วัน**, **เทมเพลต**), วางแผนรายสัปดาห์ จ–อา, **เทมเพลตสำเร็จรูป 5 ชุด (0 โทเค็น)** + **นำเข้าตารางจากข้อความหรือตาราง** และแก้ไข Template ผ่าน Preview ทันที, กรอบรูปประกอบท่า (`object-contain` + แตะซูม), โหมดเริ่มตามแผนพร้อมตัวจับเวลาพัก `30 / 60 / 90` วินาที, พับประวัติรายการตั้งแต่ลำดับที่ 6 เมื่อไม่ได้กรอง, และประเมิน RPE/RIR รายท่า
- **ติดตามร่างกาย, การนอน/ก้าวเดิน (Zepp), แดชบอร์ดตอบสนองทุกขนาดจอ & รอบเดือน:** แท็บ **แดชบอร์ด (`src/dashboard.js`)** เป็นแท็บแรกของกลุ่มสุขภาพ แสดง KPI และกราฟย้อนหลัง **3 / 6 / 12 เดือน** พร้อมแถบสลับมุมมองรวมจุดเดียวไปยัง **สรุป** (`weekly.js`) และ **รายงาน** (`reports.js`); หน้ายาวต่าง ๆ (**ร่างกาย, อาการ, ประจำเดือน, ดูแล, ของใช้, ออกกำลังกาย, การเงิน**) แบ่งแท็บย่อยด้วย `.tm-seg` แบบเดียวกับหน้ารายรับ-รายจ่ายเพื่อความกระชับบนมือถือ; ติดตามประจำเดือน, อาการและผิว, กราฟสัดส่วนร่างกาย และบันทึก **การนอนหลับ & ก้าวเดิน** (กรอกเองและนำเข้า Zepp CSV 3 รูปแบบโดยไม่ใช้ AI)

### 3. ดูแลสัตว์เลี้ยง
- **โปรไฟล์ & โภชนาการสัตว์เลี้ยง:** บันทึกน้ำหนัก คำนวณพลังงาน, เลือกจากอาหารเดิมที่เคยบันทึกได้ใน 1 คลิก (0 โทเค็น), และสแกนซองอาหารสัตว์เลี้ยงหลายรูปพร้อมความคืบหน้า `%` และหน้าต่างตรวจยืนยัน
- **บันทึกอาการน้องหมา & ผลตรวจสุขภาพ:** บันทึกระดับอาการรายวัน 6 ด้าน (ความอยากอาหาร, พลังงาน/ซึม, อุจจาระ, อาเจียน, ผิวหนัง, ไอ/หายใจ) และอุณหภูมิ (°C) แยกจากระบบแจ้งเตือน พร้อมบันทึกผลตรวจสุขภาพ (มีชุดเทมเพลต `CBC / ค่าไต / ค่าตับ / น้ำตาล & ไขมัน` และวางข้อความหลายบรรทัด 0 โทเค็น), กรองดูเฉพาะ **ค่าเลือดผิดปกติ (Abnormal)**, และสแกนใบผลเลือดหลายรูปพร้อมความคืบหน้า `%` และหน้าต่างตรวจยืนยันก่อนบันทึก

### 4. การตั้งค่า & ประสบการณ์ใช้งาน
- **เริ่มต้นใช้งานสำหรับบัญชีใหม่:** แนะนำโปรไฟล์พื้นฐาน, คีย์ AI และการแจ้งเตือนแบบเลือกทำได้ พร้อมภาพประกอบ SVG ในเครื่อง (`src/onboarding.js`); ผู้ใช้เดิมไม่ถูกบังคับผ่านขั้นตอนนี้ และความคืบหน้าจะกลับมาต่อได้บนอุปกรณ์เดิม
- **AI Chat Assistant & โหมดแพตเทิร์น 0 โทเค็น (ผู้ช่วยส่วนตัวมุมขวาล่าง):** มีโหมด **⚡ แพตเทิร์น (0 โทเค็น)** ที่ประมวลผลคำสั่งจดและเช็กสรุปในเครื่อง 100% โดยไม่ใช้ AI และไม่ต้องมี API Key (เปิดเช็กแพตเทิร์นในเครื่องก่อนเรียก AI เป็นค่าเริ่มต้น พร้อมลด `HISTORY_LIMIT = 12` และแนบ tools เฉพาะคำถามที่เกี่ยวกับ Track Me เพื่อประหยัดโทเค็น) และเมื่อเรียก AI สามารถคุยได้ทุกเรื่องด้วย **5 บทบาทเฉพาะทาง** (`คุยทั่วไป`, `โค้ชสุขภาพ`, `วางแผน & เงิน`, `วิเคราะห์ลึก`, `ตอบไว`) ที่ route โมเดลอัตโนมัติพร้อมคำสั่งเพิ่มเติมเองได้, คั่น cooldown แยกตามรายโมเดลเมื่อติดโควตา 429, แสดงผล Markdown, ช่องพิมพ์หลายบรรทัด + ปุ่มหยุดตอบ, เก็บประวัติแชทล่าสุดในอุปกรณ์, มีการ์ดยืนยันก่อนบันทึกข้อมูลสำคัญ, ปุ่มยกเลิกย้อนหลัง และระบบป้องกัน Prompt Injection (ทำงานฝั่ง Client ด้วยคีย์ Gemini, Groq หรือ OpenRouter ที่ตั้งค่าไว้)
- **ดูตัวอย่างโดยไม่เข้าสู่ระบบ (Preview Mode, `src/preview.js`):** หน้าเข้าสู่ระบบมีปุ่ม **ดูตัวอย่างก่อนใช้งาน** สำหรับเปิดสำรวจแอปด้วยข้อมูลตัวอย่างในหน่วยความจำชั่วคราวครบทุกหมวด (อาหาร การเงิน ออกกำลังกาย ร่างกาย รอบเดือน สัตว์เลี้ยง ของใช้ ผลแล็บ และแพลนเนอร์) พร้อมแถบสถานะและปุ่มออกจากโหมดตัวอย่างที่ล้างข้อมูลชั่วคราวออกอัตโนมัติ โดยไม่เขียนข้อมูลลง Firebase หรือบัญชีจริง
- **Warm Wellness Brand & UI/Accessibility:** ใช้ชุดสีประจำแอปเพียงชุดเดียวผ่าน Semantic Tokens ใน `src/design-tokens.css`; ไม่มีตัวเลือกธีมและไม่มีสีเฉพาะหมวดหมู่, Active Navigation ใช้ Soft Mint และปุ่มสำคัญใช้ Charcoal/Mint; สีสถานะ Success, Warning และ Error ยังคงแยกชัดเจน ใช้ชุดไอคอน **Phosphor Duotone** (`@phosphor-icons/core` ใน `src/icons.js`) แบบ inline SVG ทั้งแอปและทำงานออฟไลน์ 100%, แถบนำทางหลัก 4 หมวด (**อาหาร**, **สุขภาพ**, **การเงิน**, **ดูแล**) พร้อมปุ่ม **+** ตรงกลาง Bottom Nav (แตะโลโก้ **Track Me** เพื่อกลับหน้าหลัก), ใช้ตัวสลับแท็บ `.tm-seg` ทรงเดียวกันทั่วทั้งแอป, ปรับขนาดตัวอักษรบนมือถือโดยคงพื้นที่กด `>= 44px` และ input `16px`, แสดงเลขเวอร์ชันของเว็บแอป (`src/version.js`), มี focus trap + ปิดด้วย `Escape` + คืน focus ใน Modal/Bottom Sheet/Drawer/Onboarding, ปุ่ม **AI Chat** บน Header ขวาบน, ปุ่มเลื่อนหน้าจออัตโนมัติ 1 ปุ่ม, Combobox ค้นหาอาหาร, แถบวัน 7 วัน, Slider ชั่วโมงนอน, ตัวนับเลข `animateNumberTicker`, สำรองและกู้คืนข้อมูล และทดสอบคีย์ API ได้ในหน้าตั้งค่า
- ใช้ได้แบบ PWA และออฟไลน์สำหรับหน้าที่แคชไว้; หน้าและโมดูลที่ยังไม่เปิดในหน้าแรก (**รายจ่าย, แชท AI, สัตว์เลี้ยง, ของใช้, ผลแล็บ, แพลนเนอร์, อาหาร, สรุป, แจ้งเตือน, ตั้งค่า, แดชบอร์ด `dashboard.js`, รายงาน และออกกำลังกาย**) จะถูก **Lazy Load** เฉพาะเมื่อคลิกเปิดใช้งานเพื่อให้เปิดแอปได้เร็วขึ้น (การค้นหาออนไลน์และ AI ยังต้องใช้อินเทอร์เน็ต)

> **หมายเหตุ:** แหล่งโภชนาการภายนอกอาจมีโควตา จำกัดการเรียก หรือหยุดให้บริการชั่วคราว Open Food Facts/USDA อาจมีข้อจำกัดเครือข่ายและโควตา ส่วน Gemini/Groq เปลี่ยนข้อกำหนดหรือโควตาได้ Hiwpinto ใช้ bookmark helper เพราะ browser ป้องกันการอ่านพอร์ทัลล็อกอินข้ามโดเมนโดยตรง

> **AI Provider:** แอปสลับ Gemini → Groq → OpenRouter ตามคีย์ที่ตั้งไว้และสถานะโควตา; คีย์ API อยู่ฝั่ง browser และ provider จะได้รับ prompt/รูปภาพที่ส่งวิเคราะห์ โปรดอ่าน [คู่มือ AI Service](docs/AI_SERVICE.md) ก่อนใส่ข้อมูลส่วนตัว

## ซิงค์เมนูอาหารคลีนประจำสัปดาห์ (Hiwpinto)

1. เข้าเว็บไซต์ Hiwpinto ล็อกอินให้เรียบร้อย แล้วเปิดหน้า **รายการเมนูของบิลสัปดาห์ถัดไป**
2. คลิกปุ่ม **Sync Hiwpinto** บนแถบ Bookmark ด้านบน ระบบจะคัดลอกข้อมูลเมนูที่มีโภชนาการลง Clipboard อัตโนมัติ
3. กลับมาที่หน้าต่าง **Sync Data Hiwpinto** ใน Track Me กด **วางจาก Clipboard** แล้วกด **ตรวจเมนูสัปดาห์ถัดไป** เพื่อตรวจรายการและนำเข้าคลังอาหาร

*(หากยังไม่ได้สร้าง Bookmark ให้ทำตาม [วิธีตั้งค่าครั้งแรกใน docs/SETUP.md](docs/SETUP.md#hiwpinto-sync-helper-ทำครั้งเดียว))*

## โครงสร้างโปรเจกต์สำคัญ

- github/workflows/build.yml — lint, tests, Firestore Emulator, build และ deploy GitHub Pages หลัง checks ผ่านบน main
- github/workflows/daily-push.yml — ส่ง Web Push Notification สรุปแผนวันนี้และแจ้งเตือนอัตโนมัติเวลา 12:15 น. (UTC+7)
- scripts/daily-push.mjs — สคริปต์ Node.js อ่าน Firestore และส่ง Web Push (VAPID)
- scripts/check-lockfile.mjs — ตรวจความสอดคล้องของ `package.json` และ `package-lock.json` (รวม optional platform dependencies)
- firestore.rules — Firestore Rules สำหรับข้อมูลของผู้ใช้
- firestore.rules.migration — Rules ชั่วคราวสำหรับขั้นตอนย้ายข้อมูลเก่า
- public/ — ไอคอน, push-sw.js และไฟล์สาธารณะที่ Vite/PWA ใช้
- src/ — โมดูลหลักของแอป
- src/food.js และโมดูล `food*` — หน้าบันทึกอาหาร, parser, การคำนวณ, validation, Firestore service และ UI ย่อย (ดู [docs/FOOD_MODULES.md](docs/FOOD_MODULES.md))

> **การย้อนเวอร์ชันเว็บ (Rollback):** ให้สร้าง revert commit/PR จาก commit ที่ต้องการย้อน แล้ว merge เพื่อให้ GitHub Pages deploy จาก main อีกครั้ง (Tag เป็นเพียงจุดอ้างอิงเวอร์ชัน ไม่ได้ย้อน production ให้อัตโนมัติ และการเปลี่ยน Firestore Rules ต้องพิจารณาแยกจากการย้อนเว็บ)
