# Track Me

เว็บแอปจัดการชีวิตและบันทึกสุขภาพส่วนตัว ครอบคลุมอาหาร การออกกำลังกาย รายรับ-รายจ่าย ประจำเดือน อาการและผิว น้ำหนักและสัดส่วน สัตว์เลี้ยงและผลตรวจ บันทึกแจ้งเตือน และของใช้ ซิงค์ข้อมูลส่วนตัวผ่าน Google Sign-in และ Firebase Firestore พร้อมใช้งานแบบ PWA

## ความสามารถหลัก

### 1. การวางแผน & การเงิน
- **หน้า Home แบบ Weekly Planner, Week A/B, กิจวัตรวันเดียว (ไม่ซ้ำ) & สรุปภาพรวมทั้งหมด:** สลับดูสัปดาห์นี้/สัปดาห์ก่อนหน้า/สัปดาห์ถัดไป, รองรับ **กิจวัตรสลับสัปดาห์ (Week A / Week B)** พร้อมสร้างคู่สลับใน 1 คลิก และ **กิจวัตรวันเดียวแบบไม่ทำซ้ำ (`once`)**, แสดงป้ายเตือนนัดหมายด้านบน, และการ์ด **📊 สรุปภาพรวมทั้งหมด** ครบทุกมิติ (รอบเดือน, ร่างกาย/การนอน/ก้าวเดิน, โภชนาการ, การเงิน, ออกกำลังกาย, สต๊อก, แจ้งเตือน) พร้อมเพิ่มในสรุปรายสัปดาห์และรายเดือน
- **รายรับ-รายจ่าย (`expense_records`) เป็นเมนูแรกของแท็บดูแล + สแกนสลิปหลายใบ & Statement:** เก็บข้อมูลแยก 1 รายการ = 1 เอกสาร (ลดความเสี่ยงข้อมูลทับกันข้ามอุปกรณ์และส่งออก CSV รายเดือนได้) อ่านสลิปหลายรูปด้วย `tesseract.js` (`tha+eng`) แบบออฟไลน์ในเบราว์เซอร์เท่านั้น รองรับแชร์รูปสลิปตรงเข้าแอปผ่าน PWA Web Share Target และล้างรูปภาพจากหน่วยความจำทันทีหลังอ่านเสร็จ; นำเข้า Statement โดยแก้ไขชื่อผู้รับเงิน/ร้านค้า/ที่มาและหมายเหตุได้ ล้างกล่องรอตรวจได้, ระบบเรียนรู้หมวดจากรายการที่บันทึก/นำเข้าอัตโนมัติ, มีงบรายเดือนแยกตามหมวด และ **วิเคราะห์รายการจ่ายซ้ำทุกเดือนเพื่อประเมินรายจ่ายประจำต่อเดือน** พร้อมยืนยันก่อนบันทึก
- **แจ้งเตือนภาษาธรรมชาติ & ของใช้/สต๊อก:** พิมพ์เงื่อนไขแจ้งเตือนช่องเดียวพร้อม Live Preview (เช่น วันเสาร์ที่สามของเดือน, ปีหน้า, วันเดียวกับอาบน้ำหมา, ทุกวันเสาร์ที่ไม่ได้อาบน้ำหมา); ของใช้มีปุ่ม `−`/`+` 44px กดง่ายและสแกนวันหมดอายุหลายรูปพร้อมตัวเลข `%` และหน้าต่างยืนยันก่อนบันทึก
- **แจ้งเตือนอัตโนมัติ 12:15 น. แม้ไม่ได้เปิดแอป:** ใช้ Web Push Notification (VAPID) ร่วมกับ GitHub Actions ส่งสรุป Planner (รวมรอบ Week A/B) และนัดหมายเชื่อมโยงอัตโนมัติฟรี พร้อมโหมด **ซ่อนรายละเอียดส่วนตัวบนหน้าจอล็อก** เป็นค่าเริ่มต้น

### 2. สุขภาพ โภชนาการ & การออกกำลังกาย
- **บันทึกอาหารและโภชนาการ:** **สแกนอาหาร/ฉลาก/บาร์โค้ดหลายรูปพร้อมกัน (`i/N`, `%`) และหน้าต่างตรวจยืนยันก่อนบันทึก**; **เพิ่มอาหารหลายเมนูพร้อมกัน (Bulk / Quick Add)** ด้วยการวางข้อความพร้อม Live Preview; **ค้นหาโภชนาการอัตโนมัติ** (`คลังในเครื่อง → USDA → Open Food Facts → Groq → Gemini`); **คลังอาหาร** ติ๊กหลายเมนูเพิ่มลงมื้ออาหารในคลิกเดียว; รายการอาหารตัดคำ `...` ไม่ล้นจอมือถือพร้อมติ๊กย้ายมื้อเป็นชุด
- **ออกกำลังกาย (Workout Hub):** วางแผนรายสัปดาห์ จ–อา, **นำเข้าตารางจากข้อความหรือตาราง (Smart Paste / Quick Import)** และ **แก้ไข Template ผ่าน Preview ทันที** รองรับทั้งข้อความดิบ, Markdown/TSV table และจัดรูปแบบด้วย AI ให้เป็นโครงสร้าง 3 ส่วน (`Warm-up`, `Main Workout`, `Cool-down`) พร้อมค่าเริ่มต้นแบบ Beginner-Friendly, กรอบรูปประกอบท่า (`object-contain` + แตะซูม), โหมดเริ่มตามแผนพร้อมตัวจับเวลาพัก `30 / 60 / 90` วินาที, และ **ประเมินความรู้สึกหลังออก + RPE/RIR รายท่า** พร้อมคำแนะนำโหลดครั้งถัดไป
- **ติดตามร่างกาย, การนอน/ก้าวเดิน (Zepp) & รอบเดือน:** ติดตามประจำเดือน (ปรับระยะเตือนล่วงหน้าได้), อาการและผิวแบบเรียงแถว, กราฟแนวโน้มสัดส่วนร่างกายแยกดูได้ทั้ง **น้ำหนัก, รอบเอว, สะโพก, รอบแขน, รอบขา, รอบอก**, และบันทึก **การนอนหลับ & ก้าวเดิน** ได้ 3 ทาง (กรอกเอง, นำเข้าไฟล์ CSV จากแอป Zepp `ACTIVITY` + `SLEEP` พร้อมกัน, และสแกนภาพหน้าจอแอป Zepp ด้วย AI Vision) พร้อมกราฟแนวโน้มและค่าเฉลี่ย 7 วัน

### 3. ดูแลสัตว์เลี้ยง
- **โปรไฟล์ & โภชนาการสัตว์เลี้ยง:** บันทึกน้ำหนัก คำนวณพลังงาน และสแกนซองอาหารสัตว์เลี้ยงหลายรูปพร้อมความคืบหน้า `%` และหน้าต่างตรวจยืนยัน
- **บันทึกอาการน้องหมา & ผลตรวจสุขภาพ:** บันทึกระดับอาการรายวัน 6 ด้าน (ความอยากอาหาร, พลังงาน/ซึม, อุจจาระ, อาเจียน, ผิวหนัง, ไอ/หายใจ) และอุณหภูมิ (°C) แยกจากระบบแจ้งเตือน พร้อมบันทึกผลตรวจสุขภาพและกรองดูเฉพาะ **ค่าเลือดผิดปกติ (Abnormal)** และสแกนใบผลเลือดหลายรูปพร้อมความคืบหน้า `%` และหน้าต่างตรวจยืนยันก่อนบันทึก

### 4. การตั้งค่า & ประสบการณ์ใช้งาน
- **เริ่มต้นใช้งานสำหรับบัญชีใหม่:** แนะนำโปรไฟล์พื้นฐาน, คีย์ AI และการแจ้งเตือนแบบเลือกทำได้; ผู้ใช้เดิมไม่ถูกบังคับผ่านขั้นตอนนี้ และความคืบหน้าจะกลับมาต่อได้บนอุปกรณ์เดิม
- **AI Chat Assistant (ผู้ช่วยส่วนตัวมุมขวาล่าง):** พูดคุยได้ทุกเรื่องทั่วไป (ความรู้ทั่วไป ระดมสมอง ร่างข้อความ แปลภาษา) ควบคู่กับการถาม-บันทึกข้อมูลใน Track Me (รายรับ-รายจ่าย สต๊อก โภชนาการ นัด/Planner ประวัติออกกำลังกาย น้ำหนัก/สัดส่วน/การนอน/ก้าวเดิน รอบเดือน อาการ ผลตรวจ อาการสัตว์เลี้ยง รวมถึง **จดโน้ตและเก็บ Feedback จากผู้ใช้** พร้อมหน้าต่างจัดการโน้ต/Feedback `📝`); เลือก **5 บทบาทเฉพาะทาง** (`คุยทั่วไป`, `โค้ชสุขภาพ`, `วางแผน & เงิน`, `วิเคราะห์ลึก`, `ตอบไว`) ที่ route โมเดลอัตโนมัติพร้อมคำสั่งเพิ่มเติมเองได้, คั่น cooldown แยกตามรายโมเดลเมื่อติดโควตา 429 เพื่อยังสลับใช้โมเดลอื่นได้, แสดงผล Markdown, ช่องพิมพ์หลายบรรทัด + ปุ่มหยุดตอบ, เก็บประวัติแชทล่าสุดในอุปกรณ์, มีการ์ดยืนยันก่อนบันทึกข้อมูลสำคัญ, ปุ่มยกเลิกย้อนหลัง และระบบป้องกัน Prompt Injection จากข้อมูลที่เก็บไว้ (ทำงานฝั่ง Client ด้วยคีย์ Gemini, Groq หรือ OpenRouter ที่ตั้งค่าไว้)
- ธีมแอป 3 แบบ (**Cozy**, **Pastel**, **Dark mode**) พร้อมปุ่มลอยเลื่อนขึ้นบนสุด/ลงล่างสุด (`↑`/`↓`) ทุกหน้า, สำรองและกู้คืนข้อมูล (ไม่ส่งออก Push Token ของเครื่อง), ทดสอบคีย์ API (**Gemini**, **Groq**, **OpenRouter**, **USDA**) ได้ในหน้าตั้งค่า (คีย์ AI เก็บในเบราว์เซอร์ของอุปกรณ์นั้นเท่านั้น)
- ใช้ได้แบบ PWA และออฟไลน์สำหรับหน้าที่แคชไว้; การค้นหาออนไลน์และ AI ยังต้องใช้อินเทอร์เน็ต

> **หมายเหตุ:** แหล่งโภชนาการภายนอกอาจมีโควตา จำกัดการเรียก หรือหยุดให้บริการชั่วคราว Open Food Facts/USDA อาจมีข้อจำกัดเครือข่ายและโควตา ส่วน Gemini/Groq เปลี่ยนข้อกำหนดหรือโควตาได้ Hiwpinto ใช้ bookmark helper เพราะ browser ป้องกันการอ่านพอร์ทัลล็อกอินข้ามโดเมนโดยตรง

> **AI Provider:** แอปสลับ Gemini → Groq → OpenRouter ตามคีย์ที่ตั้งไว้และสถานะโควตา; คีย์ API อยู่ฝั่ง browser และ provider จะได้รับ prompt/รูปภาพที่ส่งวิเคราะห์ โปรดอ่าน [คู่มือ AI Service](docs/AI_SERVICE.md) ก่อนใส่ข้อมูลส่วนตัว

## ซิงค์เมนูอาหารคลีนประจำสัปดาห์ (Hiwpinto)

1. เข้าเว็บไซต์ Hiwpinto ล็อกอินให้เรียบร้อย แล้วเปิดหน้า **รายการเมนูของบิลสัปดาห์ถัดไป**
2. คลิกปุ่ม **Sync Hiwpinto** บนแถบ Bookmark ด้านบน ระบบจะคัดลอกข้อมูลเมนูที่มีโภชนาการลง Clipboard อัตโนมัติ
3. กลับมาที่หน้าต่าง **Sync Data Hiwpinto** ใน Track Me กด **วางจาก Clipboard** แล้วกด **ตรวจเมนูสัปดาห์ถัดไป** เพื่อตรวจรายการและนำเข้าคลังอาหาร

*(หากยังไม่ได้สร้าง Bookmark ให้ทำตาม [วิธีตั้งค่าครั้งแรกใน docs/SETUP.md](docs/SETUP.md#hiwpinto-sync-helper-ทำครั้งเดียว))*

## โครงสร้างโปรเจกต์สำคัญ

- github/workflows/build.yml — lint, tests, Firestore Emulator, build และ deploy GitHub Pages หลัง checks ผ่านบน main
- github/workflows/daily-push.yml — ส่ง Web Push Notification สรุปแผนวันนี้และแจ้งเตือนอัตโนมัติเวลา 12:15 น. (UTC+7)
- scripts/daily-push.mjs — สคริปต์ Node.js อ่าน Firestore และส่ง Web Push (VAPID)
- scripts/check-lockfile.mjs — ตรวจความสอดคล้องของ `package.json` และ `package-lock.json` (รวม optional platform dependencies)
- firestore.rules — Firestore Rules สำหรับข้อมูลของผู้ใช้
- firestore.rules.migration — Rules ชั่วคราวสำหรับขั้นตอนย้ายข้อมูลเก่า
- public/ — ไอคอน, push-sw.js และไฟล์สาธารณะที่ Vite/PWA ใช้
- src/ — โมดูลหลักของแอป
- src/food.js และโมดูล `food*` — หน้าบันทึกอาหาร, parser, การคำนวณ, validation, Firestore service และ UI ย่อย (ดู [docs/FOOD_MODULES.md](docs/FOOD_MODULES.md))

> **การย้อนเวอร์ชันเว็บ (Rollback):** ให้สร้าง revert commit/PR จาก commit ที่ต้องการย้อน แล้ว merge เพื่อให้ GitHub Pages deploy จาก main อีกครั้ง (Tag เป็นเพียงจุดอ้างอิงเวอร์ชัน ไม่ได้ย้อน production ให้อัตโนมัติ และการเปลี่ยน Firestore Rules ต้องพิจารณาแยกจากการย้อนเว็บ)

## การพัฒนาในเครื่อง (Local Development)

ต้องใช้ **Node.js 24.12** ขึ้นไป; การรัน Firestore Emulator tests ต้องมี **Java 21** ขึ้นไป

```bash
npm ci
npm run lock:check
npm run dev
npm run lint
npm test
npm run test:coverage
npm run test:rules
npm run build
```
