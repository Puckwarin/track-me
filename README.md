# Track Me

เว็บแอปบันทึกสุขภาพส่วนตัว: อาหาร/แคลอรี่ (พร้อม Gemini AI), **ประจำเดือน**, **น้ำหนักและสัดส่วน**
ซิงค์ข้ามอุปกรณ์ผ่าน Firebase Firestore และ **ใช้งานแบบออฟไลน์ได้**

## ฟีเจอร์ใหม่ (v1.1.0)
- **การ์ด "สรุปสุขภาพล่าสุด"** ด้านบนสุด: ประจำเดือนครั้งล่าสุด (LMP) + กี่วันที่แล้ว, รอบเฉลี่ย, น้ำหนักและสัดส่วนล่าสุด, และเวลา **ซิงค์ล่าสุด** — เปิดดูตอนพบแพทย์ได้ทันที มีปุ่มคัดลอกข้อความสรุป
- **แท็บประจำเดือน**: บันทึกวันเริ่ม/สิ้นสุด ปริมาณ อาการ, คำนวณความยาวรอบ ค่าเฉลี่ย และคาดการณ์รอบหน้า
- **แท็บน้ำหนัก & สัดส่วน**: น้ำหนัก รอบอก/เอว/สะโพก พร้อมกราฟแนวโน้มและส่วนต่างจากครั้งก่อน
- **ออฟไลน์**: Service Worker เก็บตัวแอป + Firestore persistent cache เก็บข้อมูล (บันทึกตอนไม่มีเน็ตได้ แล้วซิงค์เองเมื่อกลับมาออนไลน์)
- ป้ายสถานะ: ซิงค์แล้ว / กำลังซิงค์ / ออฟไลน์ · รอซิงค์
- ติดตั้งเป็นแอปบนมือถือได้ (Add to Home Screen)

## วิธีใช้ออฟไลน์
เปิดเว็บ **ตอนออนไลน์อย่างน้อย 1–2 ครั้ง** เพื่อให้เบราว์เซอร์เก็บไฟล์และข้อมูลไว้ก่อน หลังจากนั้นเปิดตอนไม่มีเน็ตได้
(ต้องเปิดผ่าน https หรือ localhost เท่านั้น เช่น GitHub Pages)

## ข้อควรระวังด้านความเป็นส่วนตัว
ข้อมูลสุขภาพแยกกันด้วย "รหัสห้อง" (room code) เท่านั้น — ควรตั้งรหัสที่เดายากและยาว
และควรตั้ง Firestore Security Rules ให้รัดกุม (ดู roadmap: Firebase Anonymous Auth)

## ไฟล์
- `index.html` — แอปทั้งหมด
- `sw.js` — Service Worker (แคชแอป/ไลบรารี CDN)
- `manifest.webmanifest`, `icon-*.png` — การติดตั้งเป็นแอป
