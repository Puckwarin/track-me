# Track Me

เว็บแอปจัดการชีวิตและบันทึกสุขภาพส่วนตัว ครอบคลุมอาหาร การออกกำลังกาย รายรับ-รายจ่าย ประจำเดือน อาการและผิว น้ำหนักและสัดส่วน สัตว์เลี้ยงและผลตรวจ บันทึกแจ้งเตือน และของใช้ ซิงค์ข้อมูลส่วนตัวผ่าน Google Sign-in และ Firebase Firestore พร้อมใช้งานแบบ PWA

## ความสามารถหลัก

### 1. การวางแผน & การเงิน
- **หน้า Home แบบ Weekly Planner, Week A/B & สรุปภาพรวมทั้งหมด:** สลับดูสัปดาห์นี้/สัปดาห์ก่อนหน้า/สัปดาห์ถัดไป, รองรับ **กิจวัตรสลับสัปดาห์ (Week A / Week B)** พร้อมสร้างคู่สลับใน 1 คลิก, แสดงป้ายเตือนนัดหมายด้านบน, และการ์ด **📊 สรุปภาพรวมทั้งหมด** ครบทุกมิติ (รอบเดือน, ร่างกาย, โภชนาการ, การเงิน, ออกกำลังกาย, สต๊อก, แจ้งเตือน) พร้อมเพิ่มในสรุปรายสัปดาห์และรายเดือน
- **รายรับ-รายจ่าย & สแกนสลิปหลายใบพร้อมกัน:** อ่านสลิปหลายรูปด้วย `tesseract.js` (`tha+eng`) แบบออฟไลน์ในเบราว์เซอร์เท่านั้น รองรับแชร์รูปสลิปตรงเข้าแอปผ่าน PWA Web Share Target, ตรวจแก้ไขเป็นชุดก่อนบันทึก, และล้างรูปภาพจากหน่วยความจำทันทีหลังอ่านเสร็จ (บันทึกเฉพาะตัวเลข/ข้อความลง Firestore)
- **แจ้งเตือนภาษาธรรมชาติ & ของใช้/สต๊อก:** พิมพ์เงื่อนไขแจ้งเตือนช่องเดียวพร้อม Live Preview (เช่น วันเสาร์ที่สามของเดือน, ปีหน้า, วันเดียวกับอาบน้ำหมา, ทุกวันเสาร์ที่ไม่ได้อาบน้ำหมา); ของใช้มีปุ่ม `−`/`+` 44px กดง่ายและสแกนวันหมดอายุหลายรูปพร้อมกัน
- **แจ้งเตือนอัตโนมัติ 08:00 น. แม้ไม่ได้เปิดแอป:** ใช้ Web Push Notification (VAPID) ร่วมกับ GitHub Actions ส่งสรุป Planner (รวมรอบ Week A/B) และนัดหมายเชื่อมโยงอัตโนมัติฟรี

### 2. สุขภาพ โภชนาการ & การออกกำลังกาย
- **บันทึกอาหารและโภชนาการ:** **สแกนอาหาร/ฉลาก/บาร์โค้ดในปุ่มเดียว**; **เพิ่มอาหารหลายเมนูพร้อมกัน (Bulk / Quick Add)** ด้วยการวางข้อความพร้อม Live Preview; **ค้นหาโภชนาการอัตโนมัติ** (`คลังในเครื่อง → USDA → Open Food Facts → Groq → Gemini`); **คลังอาหาร** ติ๊กหลายเมนูเพิ่มลงมื้ออาหารในคลิกเดียว; รายการอาหารตัดคำ `...` ไม่ล้นจอมือถือพร้อมติ๊กย้ายมื้อเป็นชุด
- **ออกกำลังกาย (Workout Hub):** วางแผนรายสัปดาห์ จ–อา, **นำเข้าตารางจากข้อความ (Smart Paste / Quick Import)** พร้อมตัวอย่างก่อนบันทึกและลิงก์อ้างอิงต่อท่า, แก้ไขบันทึกเดิม/ปรับแผน, แก้ไขเทมเพลตของฉัน, ค้นหาประวัติท่าออกกำลังกายตามชื่อท่าและช่วงวันที่
- **ติดตามร่างกาย & รอบเดือน:** ติดตามประจำเดือน (ปรับระยะเตือนล่วงหน้าได้), อาการและผิวแบบเรียงแถว, และกราฟแนวโน้มสัดส่วนร่างกายแยกดูได้ทั้ง **น้ำหนัก, รอบเอว, สะโพก, รอบแขน, รอบขา, รอบอก**

### 3. ดูแลสัตว์เลี้ยง
- **โปรไฟล์ & โภชนาการสัตว์เลี้ยง:** บันทึกน้ำหนัก คำนวณพลังงาน และสแกนซองอาหารสัตว์เลี้ยงด้วย AI
- **ผลตรวจสุขภาพ:** บันทึกผลตรวจพร้อมกรองดูเฉพาะ **ค่าเลือดผิดปกติ (Abnormal)** และสแกนใบผลเลือดหลายรายการด้วย AI

### 4. การตั้งค่า & ประสบการณ์ใช้งาน
- ธีมแอป 3 แบบ (**Cozy**, **Pastel**, **Dark mode**) พร้อมปุ่มลอยเลื่อนขึ้นบนสุด/ลงล่างสุด (`↑`/`↓`) ทุกหน้า, สำรองและกู้คืนข้อมูล, ทดสอบคีย์ API (**Gemini 3.8/3.6/3.5-lite Fallback**, **Groq Llama 3.3 / Vision**, **USDA**) ได้ในหน้าตั้งค่า (คีย์เก็บในเบราว์เซอร์ของอุปกรณ์นั้นเท่านั้น)
- ใช้ได้แบบ PWA และออฟไลน์สำหรับหน้าที่แคชไว้; การค้นหาออนไลน์และ AI ยังต้องใช้อินเทอร์เน็ต

> **หมายเหตุ:** แหล่งโภชนาการภายนอกอาจมีโควตา จำกัดการเรียก หรือหยุดให้บริการชั่วคราว Open Food Facts/USDA อาจมีข้อจำกัดเครือข่ายและโควตา ส่วน Gemini/Groq เปลี่ยนข้อกำหนดหรือโควตาได้ Hiwpinto ใช้ bookmark helper เพราะ browser ป้องกันการอ่านพอร์ทัลล็อกอินข้ามโดเมนโดยตรง

## ซิงค์เมนูอาหารคลีนประจำสัปดาห์ (Hiwpinto)

1. เข้าเว็บไซต์ Hiwpinto ล็อกอินให้เรียบร้อย แล้วเปิดหน้า **รายการเมนูของบิลสัปดาห์ถัดไป**
2. คลิกปุ่ม **Sync Hiwpinto** บนแถบ Bookmark ด้านบน ระบบจะคัดลอกข้อมูลเมนูที่มีโภชนาการลง Clipboard อัตโนมัติ
3. กลับมาที่หน้าต่าง **Sync Data Hiwpinto** ใน Track Me กด **วางจาก Clipboard** แล้วกด **ตรวจเมนูสัปดาห์ถัดไป** เพื่อตรวจรายการและนำเข้าคลังอาหาร

*(หากยังไม่ได้สร้าง Bookmark ให้ทำตาม [วิธีตั้งค่าครั้งแรกใน docs/SETUP.md](docs/SETUP.md#hiwpinto-sync-helper-ทำครั้งเดียว))*

## โครงสร้างโปรเจกต์สำคัญ

- github/workflows/build.yml — ตรวจ build สำหรับ pull request และ push ไป main
- github/workflows/pages.yml — build และ deploy GitHub Pages เมื่อมีการ push ไป main
- github/workflows/daily-push.yml — ส่ง Web Push Notification สรุปแผนวันนี้และแจ้งเตือนอัตโนมัติเวลา 08:00 น. (UTC+7)
- scripts/daily-push.mjs — สคริปต์ Node.js อ่าน Firestore และส่ง Web Push (VAPID)
- firestore.rules — Firestore Rules สำหรับข้อมูลของผู้ใช้
- firestore.rules.migration — Rules ชั่วคราวสำหรับขั้นตอนย้ายข้อมูลเก่า
- public/ — ไอคอน, push-sw.js และไฟล์สาธารณะที่ Vite/PWA ใช้
- src/ — โมดูลหลักของแอป

> **การย้อนเวอร์ชันเว็บ (Rollback):** ให้สร้าง revert commit/PR จาก commit ที่ต้องการย้อน แล้ว merge เพื่อให้ GitHub Pages deploy จาก main อีกครั้ง (Tag เป็นเพียงจุดอ้างอิงเวอร์ชัน ไม่ได้ย้อน production ให้อัตโนมัติ และการเปลี่ยน Firestore Rules ต้องพิจารณาแยกจากการย้อนเว็บ)
