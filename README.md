# Track Me

เว็บแอปบันทึกสุขภาพส่วนตัว ครอบคลุมอาหาร การออกกำลังกาย ประจำเดือน อาการและผิว น้ำหนักและสัดส่วน สัตว์เลี้ยงและผลตรวจ บันทึกแจ้งเตือน และของใช้ ซิงค์ข้อมูลส่วนตัวผ่าน Google Sign-in และ Firebase Firestore พร้อมใช้งานแบบ PWA

- แอป: https://puckwarin.github.io/track-me/
- ตั้งค่าครั้งแรกหรือสร้างโปรเจกต์ใหม่: [docs/SETUP.md](docs/SETUP.md)
- Release และ tag: [GitHub Releases](https://github.com/Puckwarin/track-me/releases)

## ความสามารถหลัก

- หน้า Home แบบ **Weekly Planner & To-Do List**: สลับดูสัปดาห์นี้และสัปดาห์ถัดไป รวมแผนออกกำลังกาย กิจวัตรประจำสัปดาห์ (Recurring Tasks เช่น ล้างจาน ล้างแก้ว เติมน้ำ) และงานรายวัน กดติ๊กเสร็จได้ทันที
- บันทึกอาหารและโภชนาการ พร้อมค้นจากคลังในเครื่อง, USDA และ Open Food Facts; ค้นหาประวัติอาหารและกรองช่วงวันที่ได้; บันทึกผลจากการถ่ายรูปจานอาหารหรือค้นหาเข้าคลังอาหารได้ทันที; AI เป็นทางเลือกสำหรับประมาณค่าและวิเคราะห์ภาพ
- ออกกำลังกายแบบวางแผนรายสัปดาห์ จ–อา, แก้ไขบันทึกเดิม/ปรับแผน, แก้ไขเทมเพลตของฉัน, ค้นหาประวัติท่าออกกำลังกายตามชื่อท่าและช่วงวันที่
- ติดตามประจำเดือน (ปรับระยะเตือนล่วงหน้าได้), อาการและผิวแบบเรียงแถว, และกราฟแนวโน้มสัดส่วนร่างกายแยกดูได้ทั้ง **น้ำหนัก, รอบเอว, สะโพก, รอบแขน, รอบขา, รอบอก**
- ดูแลสัตว์เลี้ยง: โปรไฟล์และน้ำหนัก, คำนวณและสแกนซองอาหารสัตว์เลี้ยงด้วย AI, บันทึกผลตรวจพร้อมกรองดูเฉพาะ **ค่าเลือดผิดปกติ (Abnormal)** และสแกนใบผลเลือดหลายรายการด้วย AI
- **บันทึกแจ้งเตือน** และ **ของใช้ & สต๊อก**: รวมตารางนัดสัตว์เลี้ยง รอบเปลี่ยนของ และแจ้งเตือนสำคัญ (ต่อ พ.ร.บ., ยื่นภาษี, ต่อประกัน) พร้อมตั้งระยะเตือนล่วงหน้า 1 วัน–2 เดือน และค้นหา/กรองตามช่วงวันครบกำหนด
- **แจ้งเตือนอัตโนมัติ 08:00 น. แม้ไม่ได้เปิดแอป**: ใช้ Web Push Notification (VAPID) ร่วมกับ GitHub Actions ส่งสรุป Planner และแจ้งเตือนประจำวันฟรี
- ธีมแอป 3 แบบ (**Cozy**, **Pastel**, **Dark mode**), สำรองและกู้คืนข้อมูล, ทดสอบคีย์ API (Gemini, Groq, USDA) ได้ในหน้าตั้งค่า (คีย์เก็บในเบราว์เซอร์ของอุปกรณ์นั้นเท่านั้น)
- ใช้ได้แบบ PWA และออฟไลน์สำหรับหน้าที่แคชไว้; การค้นหาออนไลน์และ AI ยังต้องใช้อินเทอร์เน็ต

แหล่งโภชนาการภายนอกอาจมีโควตา จำกัดการเรียก หรือหยุดให้บริการชั่วคราว Open Food Facts/USDA อาจมีข้อจำกัดเครือข่ายและโควตา ส่วน Gemini/Groq เปลี่ยนข้อกำหนดหรือโควตาได้ Hiwpinto ใช้ bookmark helper เพราะ browser ป้องกันการอ่านพอร์ทัลล็อกอินข้ามโดเมนโดยตรง


## ซิงค์เมนูอาหารคลีนประจำสัปดาห์ (Hiwpinto)

1. เข้าเว็บไซต์ Hiwpinto ล็อกอินให้เรียบร้อย แล้วเปิดหน้า **รายการเมนูของบิลสัปดาห์ถัดไป**
2. คลิกปุ่ม **Sync Hiwpinto** บนแถบ Bookmark ด้านบน ระบบจะคัดลอกข้อมูลเมนูที่มีโภชนาการลง Clipboard อัตโนมัติ
3. กลับมาที่หน้าต่าง **Sync Data Hiwpinto** ใน Track Me กด **วางจาก Clipboard** แล้วกด **ตรวจเมนูสัปดาห์ถัดไป** เพื่อตรวจรายการและนำเข้าเข้าคลังอาหาร

หากยังไม่ได้สร้าง Bookmark ให้ทำตาม [วิธีตั้งค่าครั้งแรกใน SETUP.md](docs/SETUP.md#hiwpinto-sync-helper-ทำครั้งเดียว)

## โครงสร้างสำคัญ

- `.github/workflows/build.yml` — ตรวจ build สำหรับ pull request และ push ไป main
- `.github/workflows/pages.yml` — build และ deploy GitHub Pages เมื่อมีการ push ไป main
- `.github/workflows/daily-push.yml` — ส่ง Web Push Notification สรุปแผนวันนี้และแจ้งเตือนอัตโนมัติเวลา 08:00 น. (UTC+7)
- `scripts/daily-push.mjs` — สคริปต์ Node.js อ่าน Firestore และส่ง Web Push (VAPID)
- `firestore.rules` — Firestore Rules สำหรับข้อมูลของผู้ใช้
- `firestore.rules.migration` — Rules ชั่วคราวสำหรับขั้นตอนย้ายข้อมูลเก่า
- `public/` — ไอคอน, `push-sw.js` และไฟล์สาธารณะที่ Vite/PWA ใช้
- `src/` — โมดูลแอป

การย้อนเวอร์ชันเว็บให้สร้าง revert commit/PR จาก commit ที่ต้องการย้อน แล้ว merge เพื่อให้ GitHub Pages deploy จาก main อีกครั้ง Tag เป็นจุดอ้างอิงเวอร์ชัน ไม่ได้ย้อน production ให้อัตโนมัติ และการเปลี่ยน Firestore Rules ต้องพิจารณาแยกจากการย้อนเว็บ
