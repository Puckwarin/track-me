# ประวัติเวอร์ชัน (Changelog)

รายการนี้สรุปการพัฒนาตามประวัติ commit, patch และ release ที่มีใน repository `Puckwarin/track-me` ส่วนรุ่นย่อยที่ไม่มี release แยกจะระบุจาก commit ที่พบ

| เวอร์ชัน | รายการพัฒนา |
|---|---|
| **v2.8.0** | เพิ่มฟีเจอร์ **เพิ่มอาหารหลายเมนูพร้อมกัน (Bulk / Quick Add Food)** พร้อม Live Preview Table ในเครื่อง (ไม่เรียก AI) รองรับรูปแบบ `[ชื่อเมนูและปริมาณ] [kcal] kcal / P / C / F` (ทั้งทศนิยม ไม่มีหน่วย `P17g` และ `p17/c32/f10`) และรูปแบบตาราง 5 คอลัมน์จาก Excel/Sheets/Markdown (`ชื่อเมนู ⇥ kcal ⇥ P g ⇥ C g ⇥ F g`) ควบคู่รูปแบบ 7 คอลัมน์เดิม; อัปเกรด **AI Fallback & Nutrition Search Pipeline** ค้นหาตามลำดับ `Local DB → USDA → Open Food Facts → Groq → Gemini` โดย Gemini วน Fallback `gemini-3.8-flash → gemini-3.6-flash → gemini-3.5-flash-lite` ทั้งเมื่อ Timeout (35 วิ) และ 429 พร้อมปรับ Groq JSON Mode (`llama-3.3-70b-versatile` / `llama-3.1-8b-instant`) |
| **v2.7.1** | แก้ปัญหา AI ค้นหาโภชนาการและวิเคราะห์ภาพ Timeout/Model Not Found: อัปเดต Gemini เป็น `gemini-2.5-flash` / `gemini-2.5-flash-lite` พร้อม `thinkingConfig: { thinkingBudget: 0 }` และขยาย Timeout เป็น 35 วินาที; อัปเดต Groq เป็น `llama-3.3-70b-versatile` / `llama-3.1-8b-instant` (ข้อความ) และ `llama-3.2-11b-vision-preview` / `90b` (ภาพ) พร้อมปรับปุ่มทดสอบการเชื่อมต่อในหน้าตั้งค่า |
| **v2.7.0** | เพิ่ม **นำเข้าตารางออกกำลังกายจากข้อความ (Smart Paste / Quick Import)** ในเมนูออกกำลังกาย พร้อมหน้าตัวอย่าง (Preview) ก่อนนำเข้า, รองรับ Plain Text และ Markdown Links, แยกชื่อโปรแกรม/กลุ่มกล้ามเนื้อ/ระยะเวลา/หมวด Warm-up·Main·Cool-down/น้ำหนัก·เซต·เวลา/คำอธิบาย/ลิงก์อ้างอิง พร้อมปุ่มเปิดลิงก์หรือค้นหา/เพิ่ม URL ในการ์ดท่า; แก้ปัญหา GitHub Actions (`package-lock.json` + คิว Deploy ไม่ชนกัน) และปรับ Daily Push ไม่ต้องสร้าง Firestore Index เพิ่ม |
| **v2.6.0** | หน้า Home ใหม่แบบ **Weekly Planner & กิจวัตร** (แยกบทบาทจาก **บันทึกเตือนเฉพาะกิจ/นัดหมายตามวันเวลา** โดยแสดงป้ายเตือนวันนั้นด้านบน Planner ไม่ปะปนกับเช็กลิสต์ออกกำลังกายและกิจวัตรประจำสัปดาห์); เพิ่ม **รายรับ-รายจ่าย & สแกนสลิปในเครื่อง** (`tesseract.js` ภาษาไทย+อังกฤษ + PWA Web Share Target แชร์รูปสลิปจากมือถือเข้าแอปโดยไม่เก็บรูปลงฐานข้อมูล); กราฟสัดส่วนร่างกายหลายมิติ; ระบบค้นหา & ตัวกรองทุกหน้าประวัติ; ระบบแจ้งเตือนอัตโนมัติเวลา 08:00 น. แม้ปิดแอปด้วย Web Push (VAPID) + GitHub Actions |
| **v2.5.0** | นำ OpenRouter ออกและเพิ่มปุ่มทดสอบคีย์ทุกตัว (Gemini, Groq, USDA); เพิ่มบันทึกลงคลังจากภาพจานอาหาร/ค้นหาโภชนาการ; รวมบันทึกแจ้งเตือน (สัตว์เลี้ยง/เปลี่ยนของ/พรบ./ภาษี/ประกัน) พร้อมตั้งเตือนล่วงหน้า 1 วัน–2 เดือนแบบรายตัวและหลายรายการ; แก้บัคกระดิ่งและเมนูของใช้กลับสัตว์เลี้ยง; ย้ายผลตรวจเข้าสัตว์เลี้ยงพร้อม AI สแกนผลเลือดและซองอาหารสัตว์เลี้ยง; Workout เพิ่มวางแผนรายสัปดาห์ จ–อา, แก้ไขบันทึกและแก้ไขเทมเพลต; อาการ & ผิว UI แนวนอนซ้าย-ขวา; สัดส่วนเพิ่มรอบแขน/รอบขา; เพิ่มตั้งเตือนรอบเดือนในหน้าแจ้งเตือน; เปลี่ยนธีมเป็น Cozy, Pastel, Dark mode |
| **v2.4.0** | ปรับปรุงการกำหนดค่าและความน่าเชื่อถือของ AI (Gemini `gemini-4-hydrogen` / `gemini-3.1-flash-lite`) |
| **v2.3.0** | แยกโหมดจัดแผนกับโหมดออกกำลังกายจริง; ปรับการ์ดท่าและจับคู่ภาพให้ตรงขึ้นพร้อม placeholder; จัดรายการเป็นกริดบน desktop; แยกคู่มือ Bookmark Hiwpinto ครั้งแรกกับการใช้งานรายสัปดาห์ |
| **v2.2.0** | Sync Helper นำเข้าเมนู Hiwpinto ของสัปดาห์ถัดไปพร้อมกันรายการซ้ำ/ตรวจพลังงาน; ค้นหาอาหารจากคลังในเครื่อง → USDA → Open Food Facts; Gemini → Groq → OpenRouter fallback และ OCR ฉลากในเบราว์เซอร์; เพิ่มภาพตัวอย่างท่าออกกำลังกายและโหมดบันทึกเซตจริง/พัก |
| **v2.1.0** | ฟอร์มบันทึกมื้ออาหาร, เพิ่มกราฟในสรุปรายเดือน |
| **v2.0.0** | Redesign UX/UI หน้าตาใหม่แบบ Cozy & Minimal Pastel ใช้งานบนมือถือง่ายขึ้น |
| **v1.6.0** | แก้เมนูเก่าที่มีน้ำหนักให้กรอก/แก้เป็นกรัม; เพิ่มสรุปรายเดือน; ยุบกลุ่มเมนูสุขภาพ/ดูแล; รวมรายการเตือน และตั้งรอบนัดสัตว์เลี้ยง; ปรับปุ่มจัดการอาหารหลายรายการให้อ่านง่ายขึ้น |
| **v1.5.0** | เพิ่มเป้าโปรตีน/ไขมันขั้นต่ำ คำนวณพลังงานออกกำลังกายโดยประมาณ สรุปรายสัปดาห์และผลตรวจ และปรับการวางแผน/สรุปพลังงานรายมื้อ |
| **v1.4.0** | ค้นหา Open Food Facts, USDA และ Gemini พร้อมกันและแสดงสถานะแยกแหล่ง; จัดกลุ่มช่อง API keys; ปรับกรอกอาหารเป็นกรัม ย้ายมื้อ คัดลอกบางรายการ และปรับ UI อารมณ์/อาการ/ผิว |
| **v1.3.0** | รวมฟีเจอร์ออกกำลังกายและเทมเพลต เป้าหมาย BMI/BMR/TDEE และมื้ออาหารที่ปรับได้; เพิ่มการค้นหาโภชนาการและดูแลสัตว์เลี้ยง/สกินแคร์/สต๊อก โดยรักษาฟีเจอร์เดิมจาก main |
| **v1.2.0** | ย้ายมาใช้ Google Sign-in และ Firestore Rules; เพิ่มบันทึกอาการ/อารมณ์ ปฏิทินและเตือนรอบเดือน คลังอาหารและอ่านฉลาก รายงานสุขภาพ สำรอง/กู้คืน และย้ายข้อมูลเดิม; ปรับเป็น Vite, Tailwind และ PWA |
| **v1.1.0** | เพิ่มติดตามประจำเดือน น้ำหนักและสัดส่วน กราฟสัดส่วน สรุปสุขภาพล่าสุด การซิงค์ และใช้งานออฟไลน์/ติดตั้งเป็นแอป |
| **v1.0.5** | แก้การเชื่อมต่อ Firebase และปรับ Firebase SDK |
